Classe .navbar

A class="navbar" é o alicerce de qualquer barra de navegação no Bootstrap. Ela é uma classe fundamental (ou estrutural) que diz ao Bootstrap: "Ei, este elemento é uma barra de navegação, prepare as regras de layout para ele".

Pensando de forma simples, ela funciona como uma "caixa organizadora". Sozinha, ela faz o seguinte:

  • Ativa o Flexbox: Ela transforma o elemento em um container Flexbox. Isso faz com que o logotipo (brand), o botão de menu (hambúrguer) e os links se alinhem horizontalmente de forma automática.
  • Define o Espaçamento Padrão: Ela aplica margens internas (padding) e alinhamentos para que os elementos lá dentro não fiquem colados nas bordas.
  • Prepara o Layout Responsivo: Ela dita como os elementos devem se comportar espacialmente antes de decidir se vão encolher ou esticar em telas menores.

Por que ela nunca anda sozinha? A classe navbar apenas cria a estrutura básica vazia. Para que ela ganhe vida, cor e o comportamento que você quer, você precisa combiná-la com outras classes. Veja o exemplo: 

<nav class="navbar navbar-expand-lg bg-light navbar-light"> ... </nav>

Aqui está o papel de cada uma nessa combinação:

classe
O que ela faz na prática?
navbar
Cria a estrutura flexível básica (o esqueleto).
navbar-expand-lg
Define em qual tamanho de tela os links aparecem abertos. Nesse caso, em telas grandes (lg), os links ficam horizontais; em telas de celular, eles se escondem atrás do botão de menu.
bg-light
Define a cor de fundo (um cinza bem claro).
navbar-light
Ajusta a cor dos textos dos links para que fiquem escuros e fáceis de ler sobre o fundo claro. (Nota: No Bootstrap 5.3+, isso mudou para atributos de tema como data-bs-theme="light", mas a lógica de contraste é a mesma).

Classe .navbar-brand

A classe .navbar-brand é utilizada para destacar o nome do projeto, da empresa ou o logótipo dentro da barra de navegação. Ela aplica automaticamente uma estilização que garante que o texto ou imagem tenha um tamanho apropriado, margens corretas e um destaque visual em relação aos outros links do menu.

Principais características:

  • Destaque Visual: Geralmente possui uma fonte ligeiramente maior ou em negrito para atrair a atenção do utilizador.
  • Alinhamento Vertical: Garante que o logótipo esteja perfeitamente alinhado ao centro da altura da navbar.
  • Link Amigável: É comum utilizá-la numa tag <a> para que o utilizador possa clicar e ser redirecionado para a página inicial.

tabelas

As tabelas no HTML são usadas para organizar dados estruturados em linhas e colunas (como uma planilha do Excel). Antigamente, elas eram usadas até para criar o layout de sites inteiros, mas hoje isso é um pecado capital: servem exclusivamente para dados tabulares.

Para criar uma tabela, nós usamos um conjunto de tags que trabalham juntas de forma hierárquica. Vamos entender cada uma delas.

As Tags Básicas (O Esqueleto)

Toda tabela padrão precisa, essencialmente, destas quatro tags:

  • <table>: É a tag mãe. Ela avisa ao navegador: "Começa aqui uma tabela".
  • <tr> (Table Row): Define uma linha da tabela. Tudo o que estiver dentro dela representará uma linha horizontal.
  • <th> (Table Heading): Define uma célula de cabeçalho. O texto dentro dela fica automaticamente em negrito e centralizado.
  • <td> (Table Data): Define uma célula de dado comum. É aqui que vai o conteúdo real da tabela.

Códigos Bootstrap utilizados

Entendendo cada tag (O que elas fazem?)

  • <table>: A tag principal que abre e fecha a tabela. No exemplo, usei a classe .table do Bootstrap para dar o visual limpo, .table-striped para zebrar as linhas e .table-hover para destacar a linha quando o mouse passa por cima.
  • <thead> (Table Head): Agrupa o cabeçalho. É onde você diz o que cada coluna significa.
  • <tbody> (Table Body): É o coração da tabela, onde ficam as linhas de dados reais.
  • <tfoot> (Table Foot): O rodapé, muito usado para exibir somatórios ou contagens.
  • <tr> (Table Row): Significa linha. Tudo o que estiver dentro de uma <tr> fará parte da mesma linha horizontal.
  • <th> (Table Header): Célula de título. O texto dentro dela fica em negrito por padrão. O atributo scope="col" avisa que ela é o título daquela coluna.
  • <td> (Table Data): Célula de dado comum. É onde você insere as informações normais da tabela.

Dicas do Bootstrap para Tabelas:

  1. Sempre use o embrulho .table-responsive: Colocar a tabela dentro de uma <div class="table-responsive"> (como fiz no exemplo) impede que a tabela quebre o seu layout em celulares. Se ela for muito grande, o Bootstrap cria uma barra de rolagem horizontal apenas na tabela, mantendo o resto da página intacto.

  2. Unir colunas (colspan): No rodapé do exemplo, usei colspan="3". Isso diz para aquela célula ocupar o espaço de 3 colunas combinadas, ideal para mensagens de totalizadores ou avisos.

my-5
No Bootstrap, o termo my-5 é uma classe utilitária usada para aplicar margens verticais a um elemento.
Para entender exatamente o que ela faz, podemos dividir o nome em três partes:

  • m : Define que a propriedade é uma Margem (Margin).
  • y : Define o eixo Vertical (eixo Y), ou seja, aplica a margem tanto no topo (top) quanto na base (bottom) ao mesmo tempo.
  • 5 : É o nível do espaçamento dentro da escala padrão do Bootstrap (que vai de 0 a 5).
navbar-toggler

Esse trecho de código é o botão "hambúrguer" do Bootstrap. Ele serve para mostrar ou esconder o menu de navegação quando o site é acessado por dispositivos menores, como celulares e tablets.

navbar-toggler : É a classe que estiliza o botão de alternância (toggle).

  • Ela remove as bordas padrões de um botão comum,
  • aplica cantos levemente arredondados,
  • define o espaçamento interno (padding)
  • e diz ao Bootstrap que este botão deve sumir em telas grandes (computadores) e aparecer apenas em telas menores.
navbar-toggler-icon

Aplicada na tag span <span class="navbar-toggler-icon"> </span>, essa classe é responsável por desenhar visualmente aquelas três barrinhas horizontais (o ícone de hambúrguer). O Bootstrap faz isso de forma inteligente usando uma imagem de fundo SVG direto no CSS, o que significa que você não precisa baixar nenhuma imagem ou ícone externo para ele aparecer.

data-bs-toggle="collapse"

Avisa ao JavaScript do Bootstrap qual é o tipo de comportamento esperado ao clicar ali.
Nesse caso, ele diz: "Esse botão vai colapsar (esconder/mostrar) algum elemento".

data-bs-target="#menuNavbar"

Indica exatamente qual elemento o botão vai controlar.
O #menuNavbar funciona como um seletor de ID do CSS.
Ou seja, em algum lugar do seu código existe uma tag (geralmente uma <div> ) com o id="menuNavbar", e é ela que vai abrir e fechar.

div class="col-12"

faz parte do sistema de grelha (Grid System) do Bootstrap e serve para definir a largura de um elemento dentro de uma linha (row). Em termos simples: ela faz com que a

ocupe 100% da largura disponível do ecrã (ou do elemento pai onde ela está inserida). Como funciona a lógica por trás disso? O Bootstrap divide o ecrã horizontalmente em 12 colunas invisíveis. Quando você define o número junto à palavra col-, está a dizer ao framework quantas dessas 12 colunas aquele bloco deve ocupar: col-12: Ocupa as 12 colunas (ou seja, 100% da largura). col-6: Ocupa metade do espaço (50% da largura). col-4: Ocupa um terço do espaço (33.33% da largura).
